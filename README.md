# TaskManager Console (TypeScript)

TaskManager es una aplicación de consola escrita en TypeScript para gestionar tareas de manera sencilla y eficiente.

## Características

- Agregar nuevas tareas
- Eliminar tareas existentes
- Marcar tareas como completadas
- Filtrar tareas por fecha
- Filtrar tareas por etiquetas (tags)

## Requisitos

- TypeScript
